# 📖 Gerador de Versículos

Criei este projeto para ter uma ferramenta simples, rápida e direto ao ponto que mostrasse versículos bíblicos de forma aleatória na tela. 

A ideia principal foi construir algo leve que rodasse 100% no navegador, sem precisar depender de APIs externas de terceiros ou conexões lentas com banco de dados.

---

### 🛠️ O que usei para fazer

* **HTML5:** Estrutura da página.
* **CSS3:** Estilização com visual dark mode para não cansar a vista e adaptação para telas de celular.
* **JavaScript:** Toda a lógica de sorteio aleatório, manipulação de elementos da tela e a biblioteca de versículos guardada direto no código.

---

### 💡 Como funciona

Ao clicar no botão de sortear, o JavaScript escolhe uma passagem da lista e atualiza o texto e a referência na tela na hora, sem precisar recarregar a página.
